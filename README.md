# Java Learning Repository

This repository is a personal Java practice space focused on learning core Java concepts, problem-solving, and Git workflows. It contains a collection of beginner-to-intermediate Java programs organized by topic.

## About

The project is meant for learning and experimentation while covering:

- Java basics and syntax
- Number systems and conversions
- Arrays and data handling
- Loops and control flow
- Pattern printing
- Sorting and recursion
- Object-Oriented Programming (OOP)
- Git and GitHub basics

## Topics Covered

- `basics` — foundational Java syntax and beginner programs
- `arrays` — working with arrays and array operations
- `loops` — `for`, `while`, `do-while`, and loop-based logic
- `Number_System` — numeric conversions and number system exercises
- `patterns` — star and pattern-based printing problems
- `sorting` — sorting algorithms and comparison logic
- `recursion` — recursive functions and problem solving
- `oops` — classes, objects, inheritance, encapsulation, and abstraction
- `git_hub` — Git/GitHub learning and related practice

## Prerequisites

Before running Java programs, make sure you have:

- Java JDK installed
- A Java IDE or terminal
- Git installed for version control practice

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/25102135-lgtm/Java.git
cd Java
```

2. Navigate to a topic folder and compile a Java file:

```bash
javac filename.java
java filename
```

3. Example workflow:

```bash
cd basics
javac Main.java
java Main
```
